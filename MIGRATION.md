# Полная миграция на Go

Новый репозиторий: `vasyza/sber-go` (private). Рабочая цель сохранена в Hermes /goal этого чата.

## Контракт

Переносится весь SDK: transport/session/cookies, строгий frontend config, SRP/RSA auth, primary/PIN/OTP/remembered-device lifecycle, все read/write resource contracts, ошибки и модели. Также переносятся безопасный CLI и MCP; write операции не включаются по умолчанию. Контроль аренды использует отдельный структурированный ledger, учитывает частичную оплату/предоплату/дубликаты и не отправляет debtor messages при неизвестной истории.

Python-версия — только эталон и источник synthetic parity fixtures, не runtime dependency. Полная исходная матрица контрактов записана в `docs/parity.json`/`docs/parity.md` и независимо проверена по AST и hashes. До закрытия всех семантических пунктов порт не считается полным.

## Уровни доказательства

1. Unit/contract/fuzz/race tests и сборка native Go binaries.
2. Real public bootstrap + browser→Go HTTP continuity с проверкой TLS.
3. Отдельный безопасный owner-operated вход и сопоставление реальных операций.
4. Повторное чтение/renewal, полная пагинация и failure handling.

Пункты 3–4 требуют владельца. Ни passing fixtures, ни публичная страница не доказывают авторизованную историю или unattended monitoring. Сообщения арендаторам и банковские операции автономно не выполняются.
