# Commit messages

Follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/):

```text
type(optional-scope): concise description

Optional explanation of the problem and resulting behavior.
```

Use `feat`, `fix`, `refactor`, `docs`, `test`, `build` or `ci` as appropriate. Mark breaking changes with `!` or a `BREAKING CHANGE:` footer. Do not add assistant attribution or co-author trailers.
